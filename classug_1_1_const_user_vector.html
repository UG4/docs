Detailed Description

template<int dim, int worldDim = dim>
class ug::ConstUserVector< dim, worldDim >

constant vector user data

Constant vector user data that can be used in assembling routines.

Parameters
dimthe dimensionality of the vector itself (for ex. 2 for vectors of two components)
worldDimthe dimensionality of the space embedding the grid (for ex. 3 for 3d PDE problems)
