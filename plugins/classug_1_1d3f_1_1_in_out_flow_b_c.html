Detailed Description

template<typename TDomain, typename TAlgebra>
class ug::d3f::InOutFlowBC< TDomain, TAlgebra >

Class of the in/outflow boundary condition: either outflow, or Dirichlet

This implementation is based on the "volume stabilization". The "volume extension" is computed by the discretization of the flow equation and stored in the volume stabilization data object. If the outflow flux is greater than 0 then the implementation is equivalent to the outflow boundary conditions. Otherwise, the Dirichlet values are set.

Remark: We use the 'flags' in the volume stabilization to mark the actual OUTFLOW boundary.
