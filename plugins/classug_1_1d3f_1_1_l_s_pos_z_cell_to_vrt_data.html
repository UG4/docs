Detailed Description

template<typename TGridFunction>
class ug::d3f::LSPosZCellToVrtData< TGridFunction >

Class for representing of z-coordinates of the level set as a continuous, vrt-centered user data

This class with the user data interface computes the z-coodinates of the level set at every grid vertex of the given subsets. In contrast to LSPosZData, this is based on a vertex-centered (but smoothed) representation. It can be used for the graphical representation of the depth of the level set on, e.g., the top surface of the domain. Note that due to the complicated evaluations, it is not recommended to pass all the subsets this computation.
