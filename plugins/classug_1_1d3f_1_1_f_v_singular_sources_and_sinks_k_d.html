Detailed Description

template<int dim, typename TPointData, typename TLineData = TPointData>
class ug::d3f::FVSingularSourcesAndSinksKD< dim, TPointData, TLineData >

Manager for Singular Sources and Sinks (SSS) using a BVH for spatial optimization.

In standard Finite Volume (FV1) schemes, finding which singular line sources intersect a specific grid element can be expensive (O(N) where N is the number of segments). This class uses a Bounding Volume Hierarchy (BVH) to reduce this to O(log N).
