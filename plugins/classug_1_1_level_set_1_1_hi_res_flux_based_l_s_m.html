Detailed Description

template<typename TGridFunction>
class ug::LevelSet::HiResFluxBasedLSM< TGridFunction >

Class of an explicit discretization of the Level-Set-Equation

This class implements the hight-resolution flux-based level-set method for the discretization of the level-set equation of the form

\begin{eqnarray*} u_t + \nabla \cdot (u \, \mathbf{V}) = u \, \nabla \mathbf{V} + r, \end{eqnarray*}

where

  • \( u \) (unknown, scalar) the level-set function (solution)
  • \( \mathbf{V} \) (given, vector) advection velocity
  • \( r \) (given, scalar) source term

The advection velocity consists of two parts:

\begin{eqnarray*} \mathbf{V} = \delta \frac{\nabla u}{\| \nabla u \|} + \gamma \mathb{V}_{\mathrm{user}}, \end{eqnarray*}

where

  • \( \delta \) (given, scalar) a scaling factor for the normal velocity
  • \( \mathbf{V} \) (given, vector) user-given velocity vector field
  • \( \gamma \) (given, scalar) a scaling factor for the user-given velocity

For the details of the method, cf.

  • P. Frolkovic, K. Mikula, High-Resolution Flux-Based Level Set Method, SIAM. J. Sci. Comput., Vol. 29(2), pp. 579–597, DOI: 10.1137/050646561
  • P. Frolkovic, Immersed Interface Method For a Level Set Formulation of Problems With Moving Boundaries, Proceedings of ALGORITHMY 2012, pp. 32–41
