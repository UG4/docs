Detailed Description

template<class TDomain, class TAlgebra>
class ug::FSFileMeasurer< TDomain, TAlgebra >

An TimeIntegratorObserver to write the height of the free surface to file, measured at given measurement points.

The measurement points have to be supplied using the add_measurement_point() or the read_measurement_points() method.
