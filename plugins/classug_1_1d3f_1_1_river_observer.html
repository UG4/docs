Detailed Description

template<typename TDomain, typename TAlgebra>
class ug::d3f::RiverObserver< TDomain, TAlgebra >

Handles river networks as a post-process of a flow problem.

This class can be attached to a time integrator. It manages the computation of a 1D surface flow sub-problem (St. Venant) and maps exchange fluxes between the surface and subsurface domains using line singular sources/sinks.

Template Parameters
TDomainThe primary (subsurface) domain type.
TAlgebraThe algebra type.
