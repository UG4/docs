Detailed Description

template<int dim>
class ug::d3f::ManningRoughness1d< dim >

Calculates the river bottom friction (reaction rate) using Manning's formula.

For a convection-diffusion formulation where the friction term is -R * v, this linker calculates the coefficient R: $$R = \frac{g \cdot n^2 \cdot |v|}{\max(h, h_{min})^{4/3}}$$
